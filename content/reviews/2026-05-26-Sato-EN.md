## One-sentence summary

This paper proposes an IMU-based method for estimating the kinematic model of a robot assembled from arbitrary rigid links, so that a robot built from on-site materials can recover its own structure after reassembly and use the estimated model for inverse-kinematics-based reaching.

![On-site building robotics workflow](/reviews/2026-05-26-Sato-EN/fig1-overview.png)

*Figure 1. Overall workflow of the proposed on-site building robotics concept: build the robot from local materials, shake it to estimate its body model, then solve inverse kinematics using the estimated link structure.*

## Problem addressed

Conventional robots are usually designed, modeled, calibrated, transported, and stored as complete systems. This assumption becomes restrictive when robots must be deployed in environments where portability and storability matter. Even if a robot can be disassembled, the total physical structure and its associated model must still be prepared in advance.

The authors propose an alternative paradigm called **on-site building robotics**. In this paradigm, only reusable joint modules are carried to the deployment site, while rigid link materials can be obtained locally. This would reduce the need to transport complete robot bodies, but it creates a central technical challenge: once the robot is assembled from arbitrary rigid components, the robot does not know the relative pose between its joints.

The core research problem is therefore: **How can a temporarily assembled robot estimate its own kinematic model using only internal sensors, without external cameras, markers, or motion-capture systems?**

## Main contribution

The paper makes the following contributions:

1. It introduces the concept of on-site building robotics, where a robot is assembled from reusable joint modules and locally available rigid links.
2. It proposes a relative-pose estimation method using pairs of IMU modules attached to rigid links.
3. It estimates relative orientation using angular velocity consistency on a rigid body and a Bingham-distribution-based filter.
4. It estimates relative position from centrifugal-force-related terms using recursive least squares.
5. It introduces a joint intermediate module containing a link holder, a servo actuator, and two IMU modules.
6. It demonstrates a wooden-stick manipulator that can estimate its kinematic model and reach a target before and after substantial physical reconfiguration.

## Method overview

The input to the method is acceleration and angular-velocity data from two IMU modules mounted on the same rigid link. The output is the relative pose between the two IMUs. Since the relative placement between each IMU and its joint module is known by design, the estimated IMU-to-IMU pose can be converted into a joint-to-joint pose and used to construct the robot kinematic model.

![Method flow](/reviews/2026-05-26-Sato-EN/fig2-method-flow.png)

*Figure 2. Relative pose estimation pipeline. The method calibrates IMU data, smooths and time-aligns measurements, estimates relative orientation, and then estimates relative position.*

### Relative orientation estimation

For two IMUs mounted on the same rigid body, the observed angular velocities should be related by a fixed rotation. The authors express this constraint in quaternion form and model uncertainty over the quaternion space using a Bingham distribution. The Bingham distribution is suitable here because it is defined over a unit hypersphere, matching the unit-norm constraint of quaternions.

The filter updates the parameter matrix of the Bingham distribution online. The mode of the distribution is extracted through eigendecomposition and used as the estimated relative rotation between IMU coordinate frames.

### Relative position estimation

Once relative orientation is known, the relative position between the IMUs can be estimated from rigid-body motion. The key observation is that sensors located at different positions on a rotating rigid body experience different acceleration components, including centrifugal and tangential acceleration. Using angular velocity, angular acceleration, and specific force measurements, the relative position vector can be formulated as the unknown in a linear equation.

The paper solves this online using a recursive least-squares formulation. A forgetting factor is used for sequential updates, and the residual covariance is used to construct a weighted update rule.

### Smoothing, differentiation, and time alignment

Relative position estimation requires the time derivative of angular velocity. Direct numerical differentiation would amplify IMU noise, so the authors use a Savitzky-Golay filter. The filter fits a local polynomial to the sensor data, which allows smoothing, derivative estimation, and interpolation.

Because different IMUs do not necessarily produce samples at exactly the same timestamps, the same polynomial interpolation strategy is also used for time alignment.

![Savitzky-Golay interpolation](/reviews/2026-05-26-Sato-EN/fig3-savgol-interpolation.png)

*Figure 3. Savitzky-Golay-based interpolation and differentiation. The local polynomial fit is used to align measurements and estimate angular acceleration.*

## Experimental design

The paper includes two levels of experimental evaluation: a controlled validation experiment using a known-length aluminum rod, and an application experiment using a wooden-stick manipulator.

### Validation experiment

In the validation experiment, two M5Stack Fire IMU modules are strapped to an aluminum rod with a known spacing of 200 mm. Because the ground-truth distance is known, the authors can evaluate position and orientation estimation error.

![Validation setup](/reviews/2026-05-26-Sato-EN/fig4-validation-setup.png)

*Figure 4. Validation setup. Two IMU modules are fixed to an aluminum rod with 200 mm spacing.*

The rod is manually shaken so that the IMUs observe angular velocity and acceleration changes. The reported maximum position error is about 3 mm, and the maximum orientation error is about 3 degrees. This suggests that the method can obtain accurate relative pose estimates in a simple rigid-link setting.

![Validation results](/reviews/2026-05-26-Sato-EN/fig5-validation-results.png)

*Figure 5. Validation results, including angular velocity, estimated relative position, position error, orientation error, and covariance-related uncertainty.*

### Joint module design

The authors design a joint intermediate module for on-site-built robots. Each module includes a link-fixing structure, a servo actuator, and two IMU sensors. One IMU is fixed to the servo motor side and the other to the servo horn side. This arrangement makes it possible to estimate the relative pose between adjacent rigid links through the proposed IMU-based method.

![Joint module](/reviews/2026-05-26-Sato-EN/fig6-joint-module.png)

*Figure 6. Joint intermediate module used in the application experiment. The module includes a link holder, servo motor, IMU modules, and 3D-printed structures.*

### Application experiment

In the application experiment, the authors build a manipulator from wooden sticks and joint modules. The task is to move the gripper above a target green box and drop a red ball into the box. No visual feedback is used. The target position is given relative to the robot reference frame, and the robot uses only the estimated kinematic model to solve inverse kinematics.

![Application experiment sequence](/reviews/2026-05-26-Sato-EN/fig7-application-sequence.png)

*Figure 7. Application experiment sequence. The robot first estimates its model and completes the task; after disassembly and reconfiguration, it estimates the model again and repeats the task successfully.*

The first estimation starts at T = 0 and ends at T = 47. The robot then solves inverse kinematics and successfully drops the ball into the box at T = 63. The robot is then disassembled, the wooden sticks are replaced, and the joint module mounting directions are substantially changed. A second estimation begins at T = 250 and ends at T = 283. The robot again moves to the target and completes the task at T = 339.

![Application estimation results](/reviews/2026-05-26-Sato-EN/fig8-application-estimation-results.png)

*Figure 8. Relative pose estimation results during the application experiment, including relative joint positions, relative joint orientations, and uncertainty estimates before and after reconfiguration.*

## Key results

1. In the known-length aluminum-rod validation experiment, the maximum relative position error is reported to be about 3 mm, and the maximum orientation error about 3 degrees.
2. The wooden-stick manipulator successfully estimates its kinematic model and completes the target-reaching task after initial assembly.
3. After the robot is disassembled, reconfigured, and rebuilt with different wooden sticks and joint-module orientations, it re-estimates its kinematic model and completes the same task again.
4. The demonstration does not rely on external vision, markers, or motion capture; the robot uses onboard IMU measurements for model estimation.

## Discussion: sampling frequency and estimation motion

The paper further analyzes the frequency response of the Savitzky-Golay filter. Since the method depends on differentiating angular velocity, the relationship between shaking frequency and IMU sampling frequency directly affects estimation quality.

![Filter frequency response](/reviews/2026-05-26-Sato-EN/fig9-filter-frequency-response.png)

*Figure 9. Frequency response of the Savitzky-Golay filter. As the ratio between swing frequency and sampling frequency increases, the estimated position-to-true position ratio deteriorates.*

The simulation suggests that when the authors use N = 3 and M = 5, the response approaches the -3 dB boundary around a swing-frequency-to-sampling-frequency ratio of about 0.3. This means that the estimation motion should not be too fast relative to the IMU sampling rate.

At the same time, stronger shaking can improve observability because it produces larger acceleration signals. Practical deployment therefore requires balancing signal strength and frequency content: the motion should excite the system enough for estimation, but not so fast that filtering and derivative estimation degrade the measurements.

## Strengths

1. **The problem setting is practical and distinctive.** The paper is not merely calibrating a conventional manipulator; it targets robots assembled from arbitrary on-site rigid materials.
2. **The method does not require external observation systems.** This is important for field robotics, where cameras, markers, or motion-capture systems may be unavailable or difficult to deploy.
3. **The estimated model remains compatible with classical robotics tools.** Once the kinematic structure is recovered, inverse kinematics can be used in a conventional way.
4. **The proof-of-concept is visually clear.** The wooden-stick manipulator successfully completing the target task before and after reconfiguration communicates the value of the idea effectively.
5. **The hardware concept is simple.** Reusable joint modules plus disposable or locally available rigid links provide a flexible robot-building strategy.
6. **The method integrates several technical components coherently.** IMU calibration, Savitzky-Golay filtering, Bingham-distribution orientation estimation, and recursive least-squares position estimation are combined into a complete pipeline.

## Limitations

1. **The experimental scale is limited.** The main application demonstration uses a relatively small wooden-stick manipulator.
2. **The method depends on the rigid-body assumption.** Flexible, vibrating, or bending links could violate the angular velocity consistency and centrifugal-force assumptions.
3. **The paper estimates kinematics, not dynamics.** Mass, inertia, damping, gravity-induced deflection, and load-dependent deformation are not modeled.
4. **The estimation motion matters.** If the shaking motion is too weak, the signal may be insufficient; if it is too fast, filtering and derivative estimation may degrade accuracy.
5. **The baseline comparison is limited.** The paper does not provide a broad quantitative comparison against motion-capture-based calibration, vision-based methods, or other inertial calibration pipelines.
6. **The demonstrated task is simple.** The application experiment focuses on planar reaching and ball dropping rather than contact-rich manipulation, payload transport, or closed-loop control under external disturbances.

## Relevance to our lab

This paper is relevant to robot self-modeling, sensor-based calibration, reconfigurable robotics, and teleoperation systems. For work on dexterous robotic hands, haptic feedback, or human-robot teleoperation, the paper provides a useful example of how a robot can recover structural information from internal sensing alone.

In teleoperation, robot-side tools, end-effectors, or task fixtures may change across experiments. A self-estimation method of this type could help recover the robot-side model without relying on external tracking. This is especially relevant when the operator-side mapping assumes a known robot-side kinematic structure.

The paper also suggests a broader design pattern: estimate the robot body first, then execute the task. For haptic or multimodal teleoperation systems, this idea could be extended so that robot-side force, tactile, or inertial signals are interpreted relative to an automatically estimated structural model.

## Discussion questions

1. How robust would this method be if the link materials are not ideal rigid bodies but bend or vibrate under load?
2. Can this approach be extended to robotic hands or multi-finger systems to estimate unknown tools or temporary attachments?
3. Can the robot actively plan the most informative excitation motion instead of relying on manually designed shaking?
4. How sensitive is the relative position estimate to imperfect IMU time synchronization?
5. Would fusing IMU data with vision, force, or tactile sensing improve robustness in non-ideal field conditions?
6. If dynamic parameters were also estimated, could the system support faster motion, payload handling, or contact-rich manipulation?

## Possible follow-up directions

1. Extend the method to longer, heavier, and higher-DOF robot structures.
2. Develop active excitation policies that automatically generate informative estimation motions.
3. Reformulate multi-link estimation as a factor-graph or graph-optimization problem to fuse constraints across multiple sensors and links.
4. Combine IMU estimation with force, tactile, or visual measurements for improved robustness when rigid-body assumptions are imperfect.
5. Extend the pipeline from kinematic model estimation to dynamic parameter estimation, including mass, inertia, and gravity compensation.
6. Test the system in more realistic field settings such as disaster-response manipulators, educational robot kits, or low-cost reconfigurable manipulation platforms.

## Overall assessment

The value of this paper lies less in presenting a mature field-ready robotic system and more in proposing a clear and technically grounded paradigm for robot construction. Instead of assuming a complete, fixed, and pre-calibrated robot body, the paper imagines a robot assembled from reusable intelligent joint modules and locally available structural materials.

For this paradigm to work, the robot must estimate its own structure after assembly. The paper provides a feasible first step toward that goal using IMU-based relative pose estimation. Methodologically, the work combines rigid-body kinematics, IMU calibration, Bingham-distribution orientation estimation, Savitzky-Golay filtering, and recursive least-squares position estimation into a coherent online estimation pipeline.

The application experiment is a convincing proof of concept: after the wooden-stick robot is reconfigured, it can re-estimate its model and still complete the target-reaching task. However, the current system remains early-stage. Broader validation under larger structures, heavier loads, flexible links, external disturbances, and more complex manipulation tasks would be necessary before the approach becomes a practical general-purpose field robotics method.
